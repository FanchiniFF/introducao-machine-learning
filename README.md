# Introdução a Machine Learning

Bem-vindo ao curso **Introdução a Machine Learning**! Este repositório contém todo o material teórico, códigos de exemplo, dados e exercícios práticos do curso ministrado na Unesp de Bauru.

## Objetivo do Curso
Capacitar iniciantes a compreenderem os conceitos fundamentais de Machine Learning, preparar dados para análise e construir os primeiros modelos preditivos utilizando as principais bibliotecas do ecossistema Python.

## Pré-requisitos
* Lógica de programação e conhecimento básico em Python.
* Noções básicas de matemática (álgebra linear e estatística descritiva).
